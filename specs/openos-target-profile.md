# Target Hardware Profile

Primary validated profile for v1:

- CPU: Intel Core i7-9850H class (x86_64, UEFI)
- RAM: >= 8 GiB
- Storage: NVMe or SATA SSD
- Input: keyboard + mouse/trackpad (non-touch first)
- Network: Intel Ethernet + common Intel Wi-Fi chipsets
- Firmware: UEFI with optional Secure Boot enabled via MOK enrollment
